# Conventions
- Centralize palette, spacing, surface, radius, and responsive decisions in `app/globals.css`.
- Use supportive, non-judgmental Turkish copy and realistic but non-sensitive sample data.
- Prefer semantic HTML and existing accessible UI primitives for interactive controls.
- Workbook topic labels are source data; normalize casing/whitespace in app data without changing the workbook.
- Separate static prototype claims from implemented backend/auth/storage capabilities.
